# chari.life

Bilingual (English / Ukrainian) tea catalogue for independent makers. Live in production at [chari.life](https://chari.life).

The catalogue covers White, GABA, Puerh sheng, Puerh shou, and Oolong, plus drink-set photography and a ceremony page. There is no cart — orders go to Telegram ([@chariteas](https://t.me/chariteas)).

Thanks to Vercel for their support of open-source software.

## Run locally

This repo is a static site. From the root:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/

- `index.html` — catalogue
- `sets.html` — drink sets
- `ceremony.html` — ceremony
